# 词语领地

朋友之间联机玩的词语接龙 × 领地经营游戏。接词成链、连链成地，在**扩张**和**加固**之间取舍。

## 玩法

1. 房主创建房间，把 4 位房间码告诉朋友（2–6 人）。
2. 开局前房主选定本局规则：允许的关系类型、是否允许专有名词、解释最少字数、回合时长、行动点、回合数、质疑次数。
3. 系统给出几个起始词。玩家轮流行动，每回合有有限行动点，可以：
   - **接词**（1 点）：点击场上任意词，接出一个有关联的新词，并写明关系解释；
   - **加固**（1 点）：让自己的一条连接免疫质疑；
   - **结束回合**。
4. 其他玩家可以在对方回合内**质疑**某条未加固的连接（次数有限）。由房主（涉及房主的词、或房主离线时，顺延给其他在线玩家）**依据开局选定的规则**裁定——不靠模型随口判断。质疑期间回合计时暂停。暂时没有在线的裁定者时无法发起质疑（不扣次数），等有合格玩家在线后再试。
5. 质疑成立：该词被拆除，**未加固的下游词级联倒塌**；加固过的下游成为新的领地根。
6. 所有人用完回合后结算：每个词得 `1 + 深度` 分，加固 +1，最长链 ×2 奖励。长链收益高，但关键连接被拆会拖累整片领地。

## 观战

没挤进对局的朋友也能只读看完整场：首页输入 4 位房间码后点**观战**，服务器分配临时观战身份（不占 2–6 人名额、不进回合顺序）。

- 大厅阶段可观战看玩家与规则；对局开始后持续收到玩家、词链、回合、计时与质疑状态推送。
- 观战者**只读**：不能接词、加固、质疑、裁定、修改规则或开始游戏（服务端双重拦截）。
- 刷新页面可凭 token 恢复观战；断线超过 60 秒自动退出，重新进入即可（服务器未重启时有效）。
- 对局**结束后观战会话即结束**：刷新页面不再自动恢复旧观战，回首页重新输入房间码即可看结算与回放；玩家凭 token 重连不受影响（要回来看结算）。结束的房间落盘时也不保留观战者与观战 token。
- 服务器重启会销毁全部连接：玩家保留座位、标记离线，凭 token 重连恢复；观战者是临时只读身份，恢复房间时会被**立即清出**（名单不残留、名额不虚占、旧 token 作废），重新输入房间码即可继续观看，不会再撞上"观战人数已满"。
- 对局结束后观战者随玩家一起进入结算，并能打开同一份局面回放。

## 历史与战绩

首页自动列出本浏览器参与过的对局：已结束的显示胜负、名次与得分，并汇总场次/胜场/胜率；进行中或大厅中的房间也会列出，方便中途回来。

- 原理：每加入一个房间，客户端把该房的玩家 token 存在本机（最多 30 条）；首页凭这些 token 向服务器换取战绩摘要，失效记录（房间已删/数据已清）会自动清掉。
- 点「进入 / 回看」即凭对应 token 重返房间：进行中回到对局，已结束回到结算面板（可打开回放）。
- 观战是临时身份，不进历史；换浏览器/清缓存后历史不可恢复（与断线重连的 token 机制一致）。

## 赛季排行榜与个人战绩

玩家完成对局后，服务端会把每名玩家的本局战绩计入**公开的赛季汇总**（独立落盘在 `data/season.json`）：首页提供**排行榜**入口，任何人（无需加入房间）都能看，也能点开任意玩家的个人页。

- **排行榜**支持三种排序：**总分、胜场、胜率**；点任意一行进入该玩家的个人页。平局（并列最高分）人人算平、无人算负；每个排序维度都有稳定的次级依据（如同分按胜场），名次不抖动。
- **个人页**汇总：场次、胜场、平局、负场、胜率、总得分、**平均得分**、**最高连锁**，以及总分榜名次与最近对局时间。
- **身份与防伪**：玩家身份不是客户端自报的。本浏览器随机生成一把**身份密钥**（localStorage `wt_pid_secret`，32 字节、只存本机、永不上榜）；公开的玩家标识 `pid` 由**服务端**从密钥派生——`pid = sha256(pidSecret)`。建房/加入时客户端提交的是密钥，服务端据此算出 pid。这样只有持有某把密钥的人才能认领对应的 pid：别人即使在排行榜上看到你的 pid，也反推不出密钥、更无法把自己的对局记到你名下（旧版本客户端自报 pid 可被冒用、污染他人战绩，该路径已在服务端关闭——自报 pid 一律忽略）。换浏览器/清缓存丢失密钥后会被当作新玩家（与本地历史/收藏一致）。
- 观战是临时只读身份，不参与对局，因此不进赛季战绩；没有有效密钥的客户端对局也不会计入。
- 每个房间只计一次（房间带幂等标记，结算广播重入、服务器重启后重连都不会重复累计）；服务器重启恢复已结束房间时不会把旧局重新算一遍。

## 战术练习

不用等朋友：首页点**战术练习**即可在本机单机练习三个固定局面，每关都写清目标与可用操作：

1. **延长词链**：2 行动点内把词链接长，体会深度分与最长链 ×2 奖励（候选词有前后置解锁关系）；
2. **保护关键连接**：只有 1 行动点加固，提交后对手自动质疑让你失分最多的目标——学会把加固花在撑着最多下游词的连接上；
3. **理解级联拆除**：选择质疑目标，一次拆掉尽量多的未加固下游，观察加固词如何截断级联、成为新根。

- 每关支持**重置**（随时回到初始局面）、**提交答案**，提交后展示双方**得分前后变化**与逐条**原因解释**（每个候选目标会拆掉几个词、失多少分、最优解是什么）。
- 通关进度保存在**本浏览器**（localStorage，`wt_practice`），列表显示「已通关 / 再练一次」；换浏览器或清缓存不保留。
- 纯前端功能，不经过服务器、不计入历史战绩。

## 个人收藏本

把赛后回看延伸成可以反复复习的词语资料：对局结束后打开**回放**，在任意一步的一条连接上点「收藏」，就把这一步的**前词、后词、关系、原解释和来源房间**一起收进首页的**收藏本**（玩家与观战者都可收藏）。

- 首页点**打开收藏本**进入：支持按前词/后词**搜索**、按关系类型**筛选**；每条可以**补充个人笔记**、随时**删除收藏**。
- **复习模式**：先只显示前词与关系，点「显示后词与解释」再揭示后词、原解释、来源房间和你的笔记，然后标记「记住了」或「还要复习」。
- 标记为「还要复习」的条目下一轮**优先出现**；列表与复习页都展示总数、已记住、还要复习、未复习的统计。
- 同一条连接（同一房间同一节点）不会重复收藏；资料全部保存在**本浏览器**（localStorage，`wt_favorites`），不经过服务器，换浏览器或清缓存不保留。

## 运行

```bash
npm install
npm start          # http://localhost:8080
```

朋友们访问同一地址（局域网用内网 IP，公网需自行部署/端口映射）即可加入。

## 测试

```bash
npm test           # 核心规则单元测试 + 自包含端到端冒烟（node:test，无需先启动服务器）
npm run test:e2e   # 单独运行端到端冒烟：进程内在临时端口自启服务器、用临时存档，跑完即停
```

> 端到端测试是自包含的：`node --test` 会执行 `test/` 下的所有 `.js`（含 `e2e.js`），
> e2e 会 require `server.js` 在系统分配的空闲端口上启动服务、使用系统临时目录中的存档，
> 结束后自动关闭并清理——不占用/冲突 8080，也不污染 `data/rooms.json`。

## 已实现

- 房间创建/加入（4 位房间码）、房主规则配置
- 回合计时（超时自动跳过）、行动点、接词/加固/结束回合
- 质疑与人工裁定（裁定期间暂停计时；涉及房主的词或房主离线时顺延裁定者，裁定者掉线自动移交）
- 级联断链：未加固下游倒塌，加固下游成为新根
- 断线重连（token 恢复身份，刷新页面即可回来）、服务器重启后房间恢复（`data/rooms.json`）
- 观战模式：房间码只读进入，实时同步玩家/词链/回合/计时/质疑，不能参与行动；结束后可看回放
- 房间历史与战绩：首页展示本机参与过的对局（场次/胜场/胜率、每局名次与得分），可凭本机会话重返进行中的房间或回看已结束的结算与回放
- 赛季排行榜与个人战绩：对局结束服务端累计公开赛季战绩（`data/season.json`），首页排行榜支持按总分/胜场/胜率排序，个人页展示场次/胜场/平局/胜率/平均得分/最高连锁
- 局面回放（事件日志重建每步盘面）、结算面板
- 个人收藏本：回放里一键收藏连接（前后词/关系/原解释/来源房间），首页入口支持词语搜索、关系筛选、个人笔记、删除；复习模式先考前词与关系、再揭示后词与解释，标记「记住了 / 还要复习」（还要复习的优先再出现）
- 首局渐进式规则提示（教学卡片随对局事件逐步出现）
- 战术练习：3 个单机固定局面（延长词链 / 保护关键连接 / 理解级联拆除），重置、提交、得分变化与原因解释，通关进度存本浏览器
